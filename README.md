# Smart-Meter-Privacy-Dashboard
Developed a Smart Meter Privacy Dashboard using Python and Streamlit to simulate household energy consumption. Implemented daily aggregation and differential privacy with Laplace noise to evaluate privacy–utility trade-offs. Designed NILM-based appliance detection to demonstrate privacy risks and visualized insights using Plotly.

Smart Meter Privacy Dashboard – How to Run
Prerequisites

Python 3.8 or higher

pip (Python package manager)

Required Libraries

Install the required dependencies using:

pip install streamlit pandas numpy plotly

Running the Application

Navigate to the project directory:

cd smart_meter_project


Run the Streamlit dashboard:

streamlit run smart_meter_dashboard.py


Open the browser link generated by Streamlit (usually http://localhost:8501).

Usage

Select different household profiles (family, student, retired, working couple).

Adjust the privacy noise scale to observe the privacy–utility trade-off.

Explore Differential Privacy vs Raw Data visualizations.

Analyze NILM-based appliance detection and observe how privacy noise affects EV detection.
